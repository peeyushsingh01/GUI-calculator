# \# GUI Calculator 🧮

# 

# A simple desktop calculator application built using \*\*Python\*\* and \*\*PySide6\*\*.

# 

# This project provides a graphical interface for performing basic arithmetic calculations without relying on Python's `eval()` function. The calculator handles user input through custom functions and maintains its own calculation state.

# 

# \## Features

# 

# \* Addition `+`

# \* Subtraction `-`

# \* Multiplication `x`

# \* Division `/`

# \* Decimal number support

# \* Negative number support

# \* Backspace functionality

# \* Clear button

# \* Division-by-zero error handling

# \* Interactive graphical user interface

# \* Custom-styled buttons and display

# 

# \## Technologies Used

# 

# \* \*\*Python\*\*

# \* \*\*PySide6\*\*

# \* \*\*Qt\*\*

#

# cd GUI-calculator

# ```

# 

# \### 2. Install PySide6

# 

# ```bash

# pip install PySide6

# ```
